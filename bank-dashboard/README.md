# ניתוח פיננסי אישי 📊

ממשק מקומי שמתחבר לבנק הפועלים ולכרטיסי האשראי שלך, מושך את התנועות **לבד** לפי תזמון,
ובונה מהן תמונה: לאן הכסף הולך, מה הבסיס הקבוע שלך, מה התייקר, ואיפה החודש הולך להיגמר.

הכל רץ אצלך על המחשב. שום נתון ושום סיסמה לא יוצאים החוצה.

---

## למה זה בנוי ככה

לבנק הפועלים **יש** API רשמי של בנקאות פתוחה — אבל הוא פתוח רק לחברות עם רישיון
"נותן שירות מידע פיננסי" מרשות ניירות ערך. הרישיון אישי ולא ניתן להעברה, ולכן אין
דרך חוקית שבה אדם פרטי מקבל גישת API לחשבון של עצמו, וגם לא דרך חברה מורשית כמו
מורנינג או רייזאפ — ה־API הציבורי שלהן לא חושף בכלל את פיד הבנק.

מה שכן עובד לאדם פרטי זה [`israeli-bank-scrapers`](https://github.com/eshaham/israeli-bank-scrapers):
ספריית קוד פתוח מתוחזקת שמריצה דפדפן, מתחברת עם הפרטים שלך ומושכת את התנועות.
זה מה שהפרויקט הזה עומד עליו.

### מה שחשוב לדעת לפני שמתחילים ⚠️

- **זה scraping, לא API רשמי.** ברוב המקרים זה מנוגד לתנאי השימוש של הבנק. השימוש באחריותך.
- **הסיסמאות שלך יושבות בקובץ `.env` על המחשב שלך.** הן נקראות לתוך התהליך ומועברות ישירות
  לספריית ה־scraper. הן לא נשמרות במסד הנתונים, לא נכתבות ללוגים, ולא נשלחות לשום שרת.
- **אל תריץ את זה על שרת בענן.** לא Railway, לא VPS, לא קונטיינר משותף. רק על מחשב שבשליטתך.
- **הממשק מאזין על `127.0.0.1` בלבד** ולא נגיש מהרשת. אל תשנה את זה.
- **הבנק עלול לשנות את האתר** ואז ה־scraper יישבר עד שהספרייה תתעדכן. זה קורה מדי פעם.
- אם הפועלים מבקש ממך אימות דו־שלבי בהתחברות, הרץ פעם אחת `npm run collect:headful`
  כדי לראות את הדפדפן ולאשר ידנית.

## התקנה

דרוש **Node.js 22.22.2 ומעלה**.

```bash
cd bank-dashboard
npm install          # מוריד גם Chromium ל-Puppeteer, לוקח דקה־שתיים
cp .env.example .env
```

עכשיו פותחים את `.env` וממלאים לפחות את פרטי הפועלים:

```
POALIM_USER_CODE=קוד-המשתמש-שלך
POALIM_PASSWORD=הסיסמה-שלך
```

אם יש לך גם כרטיסי אשראי — מלא גם אותם. הם החלק המעניין באמת: רוב ההוצאות היומיומיות
מופיעות שם בפירוט, בזמן שבחשבון הבנק הן מופיעות כשורה אחת מרוכזת בחודש.

מקור שחסר בו אפילו פרט אחד פשוט מדולג, בלי שגיאה.

## הרצה

```bash
npm run collect      # איסוף ראשון — מושך 12 חודשים אחורה, לוקח כמה דקות
npm start            # מעלה את הממשק
```

ואז נכנסים ל־**http://127.0.0.1:4000**

מרגע שהשרת רץ, האיסוף חוזר על עצמו **כל יום ב־06:00** לבד (`COLLECT_CRON` ב־`.env`).
אפשר גם ללחוץ "רענן עכשיו" בממשק בכל רגע.

### רוצה לראות איך זה נראה לפני שמחברים חשבון אמיתי?

```bash
npm run demo         # מייצר שנה של נתוני הדגמה ב-data/demo.db
npm run start:demo
```

## מה הממשק מראה

| חלק | מה יש בו |
|---|---|
| **ארבע המספרים למעלה** | הוצאות החודש מול החודש הקודם, יתרה, בסיס קבוע חודשי, תחזית לסוף החודש |
| **לאן החודש הולך** | מה כבר יצא, מה קבוע ועוד יחויב, ומה הצפי לשוטף — מול הממוצע שלך |
| **הכנסות מול הוצאות** | 12 חודשים אחורה, עם טבלה חלופית לקריאה נוחה |
| **לאן הכסף הלך** | פילוח לפי קטגוריה. לחיצה על עמודה מסננת את טבלת התנועות |
| **דברים ששווה להסתכל עליהם** | חיובים חריגים לקטגוריה שלהם, חיובים כפולים, ומנויים שהתייקרו |
| **הוצאות קבועות ומנויים** | כל מה שחוזר במרווח קבוע, כולל מה שנראה "רדום" ואולי כדאי לבטל |
| **כל התנועות** | סינון לפי חודש/קטגוריה/מקור + חיפוש, ושינוי קטגוריה בלחיצה |

### איך התובנות מחושבות

- **חיוב חוזר** — אותו בית עסק, לפחות 3 פעמים, לפחות ב־3 חודשים שונים, במרווח יציב
  (חודשי / רבעוני / חצי־שנתי / שנתי). תשלומי קרדיט לא נספרים — הם רכישה אחת מפוצלת.
- **קבוע מול משתנה** — לפי יציבות הסכום. חשמל וארנונה יסווגו כ"משתנה", נטפליקס כ"קבוע".
- **רדום** — עברה יותר מסבב וחצי בלי חיוב. סימן שהמנוי אולי בוטל.
- **חריג** — מעל חציון הקטגוריה בתוספת 5 סטיות (MAD, עמיד לחריגים), ולפחות 150 ₪.
- **כפילות** — אותו בית עסק ואותו סכום בדיוק בהפרש של עד 3 ימים.
- **תחזית** — מה שכבר יצא, ועוד חיובים קבועים שטרם חויבו החודש, ועוד קצב ההוצאה
  השוטפת של 3 החודשים האחרונים כפול הימים שנשארו.

**חיובי כרטיס אשראי מרוכזים, העברות פנימיות והפקדות לחיסכון לא נספרים כהוצאה** —
אחרת כל שקל בכרטיס היה נספר פעמיים.

## כשהסיווג טועה

הקטגוריזציה רצה על רשימת כללים בעברית ב־`src/categorize.js`. שתי דרכים לתקן:

1. **מהממשק** — שנה קטגוריה בטבלת התנועות. סיווג ידני לעולם לא נדרס באיסוף הבא.
2. **בקוד** — הוסף מילת מפתח לכלל המתאים ב־`src/categorize.js`, ואז:
   ```bash
   npm run reclassify   # מסווג מחדש את כל ההיסטוריה, פרט למה שסיווגת ידנית
   ```

## מבנה

```
bank-dashboard/
├── src/
│   ├── config.js       מקורות ופרטי התחברות מ-.env
│   ├── db.js           SQLite — סכימה, מניעת כפילויות, חלון האיסוף הבא
│   ├── collect.js      מריץ את ה-scrapers ושומר
│   ├── categorize.js   כללי סיווג בעברית
│   ├── insights.js     כל החישובים
│   ├── server.js       API + הגשת הממשק + תזמון יומי
│   ├── reclassify.js   סיווג מחדש אחרי עדכון כללים
│   └── demo.js         נתוני הדגמה
├── public/             הממשק (RTL, בהיר/כהה)
└── data/               מסד הנתונים — לא נכנס ל-git
```
