עוד לא חובר אף חשבון

כדי שהנתונים יתעדכנו לבד, צריך למלא פרטי התחברות בקובץ .env שיושב אצלך במחשב בלבד.

  1. העתק את .env.example ל־.env
  2. מלא POALIM_USER_CODE ו־POALIM_PASSWORD (ואם יש, גם כרטיסי אשראי)
  3. הרץ npm run collect — או פשוט לחץ "רענן עכשיו" למעלה
