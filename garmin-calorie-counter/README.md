# Cal Sets — אפליקציית ספירת קלוריות ל‑Garmin MARQ (Gen 2)

קאונטר "סטים" לשעון: כל לחיצה = יחידה אחת (ברירת מחדל 50 קלוריות). האפליקציה
מחברת את הספירה הידנית לקלוריות הפעילות שהשעון מודד, כך שאימון פותח לך יחידות
נוספות לאותו יום — ומסנכרנת את הכל לשרת של אפליקציית התזונה שלך.

## המסך

```
            12 SETS  x50        ← כמה סטים נספרו היום
                 ●
                  8             ← המספר הגדול: כמה סטים עוד נשארו
             SETS LEFT
          ─────────────
            600 / 2320          ← נאכל / התקציב היומי
     BASE 2000  +320 ACTIVE     ← מאיפה הגיע התקציב
              SYNCED            ← מצב הסנכרון
```

הטבעת מסביב למסך מתמלאת ככל שאוכלים. ירוקה עד 85% מהתקציב, כתומה מעל, אדומה
כשעוברים אותו — ואז המספר הגדול נהיה שלילי ומתחלף ל‑`SETS OVER`.

## הכפתורים

| פעולה | כפתור |
|---|---|
| להוסיף סט (+1) | **START** או נגיעה במסך |
| להוריד סט (‑1) | **DOWN** |
| לסנכרן עכשיו | **UP** |
| תפריט (Undo / Sync / Reset) | לחיצה ארוכה על **MENU** |
| לצאת | **BACK** (שומר ומסנכרן לפני היציאה) |

הספירה מתאפסת לבד בכל חצות, ונשמרת בזיכרון השעון — אפשר לצאת ולחזור בלי לאבד
כלום.

## החישוב

```
תקציב היום = תקציב בסיס (הגדרה) + קלוריות פעילות מהשעון
נאכל        = מספר סטים × קלוריות לסט
נשאר        = תקציב − נאכל
סטים שנשארו = נשאר ÷ קלוריות לסט (מעוגל כלפי מטה)
```

הקלוריות הפעילות נלקחות מ‑`ActivityMonitor`. בדגמים שלא חושפים את השדה הזה
ישירות, האפליקציה מחשבת אותן כ"סה"כ קלוריות פחות מטבוליזם במנוחה", לפי הגובה,
המשקל, הגיל והמין מפרופיל המשתמש בשעון (נוסחת Mifflin‑St Jeor, יחסית לחלק היום
שעבר). כדאי לוודא שהפרופיל בגרמין קונקט מעודכן.

## הגדרות

מוגדרות מהטלפון: **Garmin Connect → Connect IQ → Cal Sets → Settings**.

| הגדרה | ברירת מחדל | מה זה |
|---|---|---|
| `Server URL` | ריק | הכתובת המלאה של ה‑endpoint בשרת שלך |
| `API key` | ריק | נשלח בכותרת `X-Api-Key` |
| `Kcal per set` | 50 | כמה קלוריות שווה לחיצה |
| `Base daily budget` | 2000 | תקציב הבסיס לפני פעילות |
| `Add active calories` | כן | האם להוסיף את הקלוריות הפעילות לתקציב |
| `Auto sync` | כן | לשלוח לשרת אחרי כל לחיצה |

כל עוד `Server URL` ריק, האפליקציה עובדת מצוין אופליין — פשוט בלי סנכרון.

## בנייה והתקנה

### 1. להתקין את ה‑SDK

1. להוריד את **Connect IQ SDK Manager** מ‑`developer.garmin.com/connect-iq/sdk`.
2. להתקין את ה‑SDK האחרון, ובתוך ה‑Manager להוריד גם את הדגם **MARQ (Gen 2)**.
3. להוסיף את תיקיית `bin` של ה‑SDK ל‑PATH.

### 2. לייצר מפתח מפתח (פעם אחת)

```bash
cd garmin-calorie-counter
openssl genrsa -out developer_key.pem 4096
openssl pkcs8 -topk8 -inform PEM -outform DER \
  -in developer_key.pem -out developer_key.der -nocrypt
```

המפתח ב‑`.gitignore` ולא נכנס לריפו. כדאי לשמור עליו — הוא מזהה אותך כמפרסם.

### 3. לבנות

```bash
./build.sh             # bin/CalSets.prg עבור marq2
./build.sh marq2 release   # bin/CalSets.iq לחנות
```

### 4. לבדוק בסימולטור (בלי השעון)

```bash
connectiq                       # מפעיל את סימולטור השעון
monkeydo bin/CalSets.prg marq2
```

### 5. לטעון לשעון

1. לחבר את השעון למחשב בכבל USB.
2. השעון מופיע כדיסק בשם `GARMIN`.
3. להעתיק את `bin/CalSets.prg` לתיקייה `GARMIN/APPS`.
4. לנתק בבטחה ולהפעיל מחדש את השעון — האפליקציה תופיע ברשימת האפליקציות.

> אם `monkeyc` נופל עם `Invalid device ID found in the manifest`, מזהה הדגם
> ב‑`manifest.xml` לא תואם למה שה‑SDK מכיר. רשימת המזהים החוקיים היא שמות
> התיקיות תחת:
> `~/Library/Application Support/Garmin/ConnectIQ/Devices` (macOS) או
> `%APPDATA%\Garmin\ConnectIQ\Devices` (Windows).
> מעתיקים משם את השם המדויק של MARQ Gen 2 ומעדכנים את `<iq:product id="...">`.

## חיבור לשרת התזונה ב‑Railway

בכל סנכרון האפליקציה שולחת `POST` עם גוף JSON:

```json
{
  "source": "garmin",
  "date": "2026-08-09",
  "sets": 12,
  "kcalPerSet": 50,
  "consumedKcal": 600,
  "activeKcal": 320,
  "totalKcal": 1850,
  "baseBudgetKcal": 2000,
  "allowanceKcal": 2320,
  "remainingKcal": 1720,
  "steps": 8412,
  "ts": 1786000000
}
```

בכל פעם נשלח **מצב היום המלא**, לא דלתא — אז אפשר פשוט לדרוס את הרשומה של
אותו תאריך, וסנכרון כפול לא מזיק. כל תשובה בטווח `2xx` נחשבת הצלחה; כל דבר אחר
משאיר את היום מסומן כ"לא סונכרן" והשליחה תחזור על עצמה בלחיצה הבאה או בפתיחה
הבאה של האפליקציה.

בתיקייה `server/` יש endpoint מוכן לשרת ה‑Node שלך:

```js
const express = require("express");
const garmin = require("./garmin-endpoint");

const app = express();
app.use(express.json());
app.use("/garmin", garmin({ apiKey: process.env.GARMIN_API_KEY }));
```

ואז ב‑`Server URL` בשעון מזינים:
`https://<your-app>.up.railway.app/garmin/sets`

הוא חושף גם `GET /garmin/sets` (כל הימים) ו‑`GET /garmin/sets/2026-08-09` (יום
בודד), כדי שאפליקציית התזונה תוכל לקרוא את הנתונים.

## הערות

- **הסנכרון עובר דרך הטלפון.** השעון שולח בקשות רשת רק כשהוא מחובר ב‑Bluetooth
  לטלפון עם Garmin Connect פתוח ברקע. בלי טלפון יופיע `NO PHONE`, הספירה תמשיך
  כרגיל, והכל יישלח כשהחיבור חוזר.
- **הטקסט באפליקציה באנגלית בכוונה.** לשעוני גרמין אין פונט עברי מובנה ואין
  תמיכה ב‑RTL, אז עברית תיראה כריבועים או הפוכה. המספרים הם העיקר ממילא.
- **סוללה.** האפליקציה מציירת מחדש כל 30 שניות בזמן שהיא פתוחה, ולא רצה ברקע.
