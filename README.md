# עברית ישרה

כלי קטן שמציג טקסט עברי מ‑Claude בצורה ישרה ונכונה — מימין לשמאל, בעיצוב שנראה כמו שיחה רגילה ב‑Claude.

מדביקים הודעה, והיא מופיעה מיושרת נכון עם כותרות, הדגשות ורשימות — במקום להיות הפוכה ולא קריאה.

## 🐍 SNAKE — קלאסיקה מלוטשת

בונוס: משחק סנייק רטרו בעיצוב פרימיום — קובץ עצמאי אחד, `snake.html`. זמין בכתובת `/snake.html` כשהשרת רץ, או פשוט פותחים את הקובץ בדפדפן. חצים / WASD / החלקה במובייל.

## הרצה מקומית

```bash
npm start
```

ואז נכנסים ל‑http://localhost:3000

## פריסה ב‑Railway

1. נכנסים ל‑[railway.app](https://railway.app) ומתחברים עם GitHub.
2. **New Project → Deploy from GitHub repo** ובוחרים את הריפו הזה.
3. בוחרים את הענף שבו נמצא הקוד.
4. Railway מזהה אוטומטית שזה פרויקט Node ומריץ `npm start`.
5. תחת **Settings → Networking** לוחצים **Generate Domain** כדי לקבל כתובת ציבורית.

אין צורך במשתני סביבה — Railway מספק את `PORT` והשרת מקשיב עליו לבד.
